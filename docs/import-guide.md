# AI-READONLY: 飞书、Codex 与 ima 历史资料导入

当前未连接飞书或 ima，也未扫描过去两年的 Codex 聊天。平台能否全量导出、连接器权限和历史覆盖范围需要实际核验。

## 导入流程

1. 在平台已授权连接器或本人导出的资料中确定范围；读取与公开发布分开授权。
2. 在仓库外的私有暂存区处理原文；不要把导出文件先提交再删除。
3. 仅提炼个人公开职业标签、明确沟通偏好、通用工作方法和允许公开的经验。过滤雇主机密、候选人/客户信息、联系人、账号、财务等。
4. 每条候选包含脱敏来源、日期、置信度、适用条件；不能用可访问的私人文档标题或 ID 暴露内部信息。
5. 给本人审阅具体摘要；只有被确认允许公开的内容才提交公开仓库 PR。核心身份事实不能仅依据上下文推断。
6. 记录来源覆盖的时间范围、数量和未覆盖平台，不声称已读取全部历史。

若需要保留完整个人资料，使用独立私有仓库和最小权限访问；本公开模板仓库只保留可公开层。
